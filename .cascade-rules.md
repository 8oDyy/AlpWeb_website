# AlpWeb Website - Règles du Projet

## 📁 Structure du Projet

```
AlpWeb_website/
├── app/
│   ├── assets/css/          # Styles globaux (Tailwind)
│   ├── components/          # Composants Vue réutilisables
│   ├── composables/         # Composables Vue (useGsap, etc.)
│   ├── layouts/             # Layouts Nuxt (default.vue)
│   ├── pages/               # Pages du site (routing automatique)
│   ├── plugins/             # Plugins Nuxt (lenis, gsap)
│   └── utils/
│       └── data/            # Données statiques (services, projets, témoignages)
├── public/                  # Assets statiques (images, favicon)
├── .cascade-rules.md        # Ce fichier - règles du projet
├── .env.example             # Variables d'environnement exemple
└── nuxt.config.ts           # Configuration Nuxt
```

## 🛠 Stack Technique

- **Framework**: Nuxt 4 (Vue 3, SSR)
- **Langage**: TypeScript
- **Styles**: Tailwind CSS 4 + Nuxt UI 4
- **Animations**: GSAP + ScrollTrigger
- **Smooth Scroll**: Lenis
- **Fonts**: Inter, Manrope (via @nuxt/fonts)
- **Icons**: Lucide (via @nuxt/icon)
- **Linting**: ESLint + @nuxt/eslint

## 📝 Conventions de Code

### Composants Vue
- Utiliser `<script setup lang="ts">` pour tous les composants
- Nommer les composants en PascalCase
- Préfixer les composants de base avec `Base` (ex: `BaseButton.vue`)

### Styles
- Utiliser Tailwind CSS pour le styling
- Éviter les styles scoped sauf nécessité
- Variables CSS dans `assets/css/main.css`

### Animations GSAP
- Utiliser le composable `useGsap()` pour les animations
- Attributs data pour les animations scroll: `data-animate`, `data-delay`, `data-duration`
- Toujours cleanup les animations avec `onUnmounted`

### TypeScript
- Typer toutes les props et émits
- Interfaces dans des fichiers `.ts` dédiés
- Éviter `any`, préférer `unknown` si nécessaire

## 🎨 Design System

### Couleurs
- Primary: Défini dans Nuxt UI (personnalisable)
- Utiliser les classes Tailwind: `text-primary-500`, `bg-primary-100`, etc.

### Typographie
- Titres: font-family `Manrope`
- Corps: font-family `Inter`
- Classes: `font-sans` (Inter), `font-display` (Manrope)

### Espacements
- Sections: `py-24` (96px)
- Container: `container mx-auto px-4`
- Gaps: `gap-4`, `gap-8`, `gap-16`

## 🚀 Commandes

```bash
pnpm dev          # Serveur de développement
pnpm build        # Build production
pnpm generate     # Génération statique
pnpm preview      # Preview du build
pnpm lint         # Vérification ESLint
pnpm lint --fix   # Correction automatique
```

## 📦 Déploiement

- **Plateforme**: Vercel
- **Build Command**: `pnpm build`
- **Output Directory**: `.output/public` (pour static) ou `.output` (pour SSR)

## ⚠️ Points d'Attention

1. **SEO**: Toujours utiliser `useSeoMeta()` dans les pages
2. **Images**: Optimiser les images avant de les ajouter à `/public`
3. **Animations**: Tester les performances sur mobile
4. **Accessibilité**: Respecter les standards WCAG
