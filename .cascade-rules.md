## 🔀 Git & Workflow (OBLIGATOIRE)

### Branches
- **Ne JAMAIS coder sur `main`**
- Créer des branches de feature : `feat/xxx`, `fix/xxx`, `style/xxx`
- Merger dans `dev` puis `dev` → `main`

### Commits
Format : `type: description courte`
```
feat: add animated hero section
style: adjust typography scale
fix: lenis scroll jitter on mobile
chore: add dependencies
docs: update global rules
```

### Checklist AVANT chaque commit
- [ ] `pnpm lint` passe ✅
- [ ] `pnpm typecheck` passe ✅
- [ ] Pas de `console.log` oubliés
- [ ] Imports inutiles supprimés

### CI GitHub Actions
Le CI vérifie automatiquement :
1. **Lint** (`pnpm lint`)
2. **TypeCheck** (`pnpm typecheck`)
3. **Build** (`pnpm build`)

**⚠️ Ne pas push si le CI va échouer !**

## 🎨 Design System (Crème/Noir)

### Palette
```css
--color-cream: #F5F0E8;        /* Fond principal */
--color-cream-dark: #EBE4D8;   /* Fond secondaire */
--color-cream-light: #FAF8F5;  /* Fond clair */
--color-black: #1A1A1A;        /* Texte principal */
--color-black-soft: #2D2D2D;   /* Texte secondaire */
--color-black-muted: #4A4A4A;  /* Texte tertiaire */
```

### Classes utilitaires
- Fonds : `.bg-cream`, `.bg-cream-dark`, `.bg-alp-black`
- Textes : `.text-alp-black`, `.text-alp-black-soft`, `.text-alp-black-muted`
- Cards : `.card-premium`
- Container : `.container-alp`
- Sections : `.section-padding`

### Typographie
- **Titres** : Manrope (`.font-display`)
- **Corps** : Inter (`.font-sans`)

## 📝 Conventions de Code

### Vue Components
```vue
<script setup lang="ts">
// 1. Imports
// 2. Props & Emits (typés)
// 3. Composables
// 4. State réactif
// 5. Computed
// 6. Methods
// 7. Lifecycle (onMounted, onUnmounted)
</script>
```

### Animations GSAP
- Config dans des **composables dédiés** (`useHeroAnimations.ts`)
- **Toujours cleanup** avec `gsap.context()` + `ctx.revert()` dans `onUnmounted`
- Pas de logique d'animation dans les templates

### TypeScript
- Typer toutes les props, emits, retours de fonctions
- Éviter `any` → utiliser `unknown`
- Interfaces en haut du fichier ou fichier dédié

## ⚠️ Points d'Attention

1. **CI** : Toujours vérifier `pnpm lint` et `pnpm typecheck` avant commit
2. **SEO** : Utiliser `useSeoMeta()` dans chaque page
3. **Animations** : Cleanup obligatoire, tester sur mobile
4. **Performance** : Optimiser images, lazy load si nécessaire
5. **Accessibilité** : Standards WCAG, aria-labels
